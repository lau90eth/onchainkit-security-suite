# Changelog

## Unreleased

### Added
- `useNetworkGuard` — wrong network detection and switch
- `useTransactionHistory` — paginated transaction history
- `useContractVerification` — contract security analysis
- `useTokenAllowance` — ERC-20 allowance auditing
- `useRevokeAllowance` — one-click allowance revocation
- `useGasEstimator` — real-time gas with spike detection
- `useTransactionSimulation` — simulate transactions before signing
- `useWalletRisk` — analyze destination wallet risk before sending
- `<SecurityCheck />` — visual security summary component

### Examples
- basic-dapp — full security coverage example
- allowance-manager — audit and revoke approvals
- secure-swap — swap with all security checks

### Docs
- Full API documentation for all hooks
- Usage examples for each component

## Status

All hooks are open PRs on coinbase/onchainkit.
This repo provides standalone versions usable today.
